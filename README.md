### 1. はじめに

TiermakerをはじめとするTierリスト生成ツールは、コンテンツの比較・評価・分類の手段として広く利用されている。これらのツールでは、ユーザーは対象をドラッグ＆ドロップ操作によってS・A・B・Cといった事前定義されたカテゴリへ直接配置する。しかし候補数が多い場合や要素間の差異が微細である場合、ユーザーは各要素の絶対的な質を即座に判断しなければならず、高い認知負荷が生じうる。

この問題を回避するアプローチとして、「2択比較の反復」によるソート、すなわちペア比較に基づくアルゴリズム（マージソート等）の採用が考えられる。この形式ではユーザーは都度「どちらが上位か」を選ぶだけでよく、全体の格付けを即座に意識する必要がない。しかし、この手法には別の困難が生じうる。完全な全順序を確定するには $O(n \log n)$ 回の比較を要し、比較作業が長時間化する可能性がある。加えて、人間の主観的評価においては $A \succ B$、$B \succ C$、$C \succ A$ となる巡回的選好（非推移的選好）が生じうるが、厳密なソートアルゴリズムはこうした矛盾を許容せず、ユーザーに選好の一貫性を強いる。

本稿では、これら両形式の問題を緩和することを目的として、二項比較の積み重ねから確率的スコアを推定し、Tierリストを漸進的に構成するシステムを提案・実装した。

### 2. 提案システム

#### 2.1 Glickoレーティングによる確率的順位推定

厳密な順序決定アルゴリズムに代えて、競技チェスや対戦ゲームの格付けに用いられるGlickoレーティングシステムを採用した。

各要素にレーティング $r$ と信頼幅$RD$ を付与し、二択の選択結果から逐次更新する。これにより二つの性質が期待される。

巡回的選好の許容。順位を静的な順序ではなく確率的スコアとして管理するため、選好に矛盾が生じてもシステムは破綻しない。巡回する選好はスコアの揺らぎとして吸収され、全体として整合的な推定値へ収束することが期待される。

少数比較による暫定順位の提示。新規要素に対しては $RD$ が大きく保たれるため、少数の比較でも広いスコア帯をカバーし、早期から有意な暫定順位を提示しうる。比較の蓄積とともに $RD$ は縮小し、推定精度の向上が見込まれる。

#### 2.2 段階的な評価ワークフロー

本システムは、比較による順位形成と手動微調整を組み合わせたワークフローを想定する。ユーザーはまず2択の選択を反復することで、全体の粗い順位を漸進的に形成する。各比較は認知的に比較的軽い判断であり、集中的な格付け作業を必要としない。

その後、得られたスコア順位をそのまま最終出力として採用することも、あるいはTierラベルの付与やドラッグ＆ドロップによる手動補正を経てTier表として仕上げることも可能である。スコアや自動推定が捉えきれない文脈依存の判断は、手動操作によって補完できる。Tierラベルの付与は任意であり、比較のみで完結するユースケースも想定している。

### 3. 考察

本システムの核心は、比較による確率的推定と任意の手動補正を組み合わせた柔軟な評価ワークフローにある。ユーザーは評価の開始時点から全体の格付けを完成させることを強いられず、また選好の矛盾を無理に解消することも要求されない。

巡回的選好はその存在を否定されるのではなく、確率的なスコア推定の誤差として吸収され、最終的な順位表においては近接したスコア帯の要素群として表出しうる。このような人間の選好のあいまいさへの寛容性が、従来の決定論的ソートや直接的なTier配置に対する本システムの差別的優位となりうる。

一方で限界も存在する。Glickoレーティングは適切な収束のために一定数の比較を必要とし、比較数が極めて少ない場合はスコアの信頼性が低くなる可能性がある。また、候補数が増加するにつれ全比較の網羅性は低下する。
